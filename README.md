# Feelings Adventure Lab

A mobile-friendly, interactive emotional-learning website for children around age 10. It includes emotion check-ins, body-clue mapping, thought reframing, breathing and grounding exercises, communication practice, empathy challenges, and a personal coping plan.

## Publish with GitHub Pages

1. Upload everything in this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The English page is at `/`. The Chinese page is at `/zh/` and includes a Simplified/Traditional Chinese switch. No build process or external dependencies are required.

All user entries are stored only in the browser's local storage and are not transmitted anywhere.
